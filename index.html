Wayne Free Host 服務條款

更新日期：2026 年 10 月 14 日

適用範圍與同意

歡迎使用 Wayne Free Host（以下簡稱「本服務」）。本服務為免費提供之主機服務，使用者完成註冊或建立伺服器，即視為已閱讀、瞭解並同意本條款之全部內容。如不同意本條款，請勿註冊或使用本服務。

1. 服務性質

本服務所提供之全部資源均為免費性質，不提供專人客服，亦不提供任何形式之服務保證。

1.1 服務內容之調整

基於維護、重組或終止營運之需要，管理員（Wayne）得隨時變更、暫停或終止本服務之全部或一部，且無須事先通知使用者。

1.2 不保證服務可用性

本服務不保證全年無休或不中斷運作，亦不提供企業等級之服務水準協議（SLA）。Discord 社群中之協助，屬成員間之互助性質。

1.3 維護與不可抗力

本服務可能因維護需要而暫停，管理員將盡力事先通知，並於預定時間內完成。因維護、停電、網路中斷、天災或其他無法控制之因素，所致之服務中斷或資料損失，本服務不負賠償責任。

2. 帳號與安全管理

為確保使用之公平性與服務之安全，使用者應遵守下列帳號與資訊安全要求。

2.1 每人限一帳號

每位使用者限註冊並使用一個帳號，不得以建立多個帳號之方式取得額外資源。經查證有多重帳號者，相關帳號將一併永久停權。

2.2 帳號保管責任

使用者應妥善保管其帳號與密碼。以該帳號進行之一切行為，均視為使用者本人之行為，並由使用者負責。

2.3 登入失敗之自動防護

系統設有自動防護機制：VPS 連續三次輸入錯誤密碼者，其來源 IP 位址將遭自動封鎖。如因誤操作遭封鎖，請聯繫管理員申請解除。

2.4 禁止轉讓與轉售

未經管理員同意，不得將帳號或伺服器轉讓、出租、轉售，或提供他人共同使用。

3. 資源配額與使用限制

由於資源有限，使用者應合理使用，不得影響其他使用者之權益。

3.1 伺服器數量

一般使用者同時最多可開啟 5 台伺服器；管理員最多 10 台。

3.2 運算資源配額

一般使用者每台伺服器之上限為 CPU 20%、RAM 512 MB；管理員不在此限。

3.3 CPU 使用限制

伺服器之 CPU 使用率於一小時內，不得長時間維持於 80% 以上。情節嚴重者，系統得降低其效能或強制關機。

3.4 磁碟空間上限

一般使用者每台伺服器之磁碟空間（Pterodactyl 面板之 Disk）上限為 1 GB，管理員另行配置。伺服器內所有檔案，包含世界存檔、日誌、暫存檔、模組、node_modules 及備份檔，均計入用量，並以面板顯示之數據為準。

3.5 超過磁碟配額之處理

磁碟用量超過上限時，面板得阻止伺服器啟動、無法上傳或寫入檔案，並可能導致存檔損毀或遺失。使用者應於收到通知後 48 小時內自行清理；逾期者，管理員得直接刪除超額檔案（優先處理日誌、暫存檔及備份）或停用伺服器。因超額造成之資料損毀或遺失，本服務不負任何責任。

3.6 禁止規避磁碟限制

禁止以符號連結（symlink）、掛載外部儲存、將資料置於容器以外之位置、偽造檔案大小或其他方式規避磁碟配額。違者視同違反第 4.10 條，並將停用其伺服器。

3.7 備份、資料庫與埠口

每台伺服器最多得設置 1 份備份、1 個資料庫及 2 個網路埠口（Allocation）。

備份提醒

面板上之備份不屬於異地備份。請定期將備份檔下載至個人裝置自行保存。

3.8 檔案數量、單檔大小與頻寬

單一伺服器之檔案總數不得超過 50,000 個，單一檔案不得超過 500 MB。磁碟 I/O 或網路頻寬長時間異常偏高並影響其他使用者時，管理員得要求清理、限速或停用伺服器。

4. 禁止行為

下列行為一律禁止。違反者，管理員得依第 9 條逕行處置。

4.1 加密貨幣挖礦

禁止執行任何加密貨幣挖礦程式（例如 XMRig）。經系統偵測者，立即停權帳號，不另行通知或協商。

4.2 惡意攻擊與爬蟲

禁止利用本服務發動分散式阻斷服務（DDoS）攻擊、網路掃描、洪水攻擊，或進行高頻率之惡意爬蟲。

4.3 惡意程式

禁止存放或執行木馬、病毒、勒索軟體，或任何遠端控制後門程式。

4.4 高風險內網穿透工具

重點規定

為確保安全，禁止於容器內擅自架設 sshx、tmate，或未經授權之 ngrok、cloudflared 等高風險隧道工具。違者將停用其伺服器。

4.5 作業系統映像

禁止於容器內下載、安裝或執行完整之 Linux、Windows 或其他作業系統映像、ISO、rootfs，亦禁止於容器內建立巢狀虛擬機或容器。一般應用程式運作所需之套件下載，不在此限。

4.6 色情與違法內容

禁止任何色情內容（包含 AI 生成之色情內容、成人網站等）及其他違反法令之內容。

4.7 濫用儲存與頻寬

禁止將本服務作為公開檔案分享、盜版散布、代理轉發、大量下載站，或其他長時間大量耗用儲存空間與頻寬之用途。

4.8 未經授權之存取

禁止嘗試登入、讀取、修改或破壞其他使用者、伺服器、面板或主機系統之資料與功能。

4.9 垃圾訊息與大量自動化請求

禁止發送垃圾郵件、大量建立帳號、洗版、傳送騷擾訊息，或以程式持續發送足以影響服務穩定性之高頻率請求。

4.10 規避資源限制

禁止以多開帳號、程序偽裝、利用漏洞或其他方式，規避伺服器數量、CPU、記憶體及頻寬等資源限制。

4.11 盜版、破解與 P2P 下載

禁止存放或散布盜版軟體、破解工具及 ROM；禁止使用 BitTorrent 等 P2P 工具下載或做種；提供前述內容之連結或教學之網站，亦在禁止之列。

4.12 代理與 IRC

禁止架設代理（Proxy）或 VPN 轉發節點，亦禁止建立或連接 IRC 網路伺服器。初次違反者，停用其伺服器；再次違反者，終止其帳號。

4.13 不實與誹謗內容

禁止架設用於散布不實資訊，或誹謗、毀損個人、團體、企業名譽之網站與服務。

4.14 冒充與社交工程

禁止冒充管理員、工作人員或其他使用者，亦禁止以任何方式詐取他人之密碼、驗證碼、Token 或權限。

4.15 侵害他人隱私

禁止蒐集、公開或交易他人之個人資料（包含人肉搜索，以及將 Discord 私訊與管理員對話截圖外流），亦禁止於伺服器上架設未經當事人同意而蒐集個人資料之網站或程式。

4.16 濫用面板與 API

禁止暴力嘗試登入、濫用面板 API 或 SFTP、短時間內反覆建立與刪除伺服器，或以任何方式探測面板與節點之漏洞。

4.17 外洩憑證與敏感資料

禁止將面板帳號密碼、API Key、SFTP 密碼、Token 或 .env 之內容公開或張貼於公開場合。因此遭盜用所造成之後果，由使用者自行負責。

5. 閒置與回收規則

使用者應定期使用並維持伺服器之運作狀態。

5.1 建立後七日內無操作

伺服器建立後 7 日內，未有開機、登入、部署或其他操作者，管理員得直接刪除該伺服器，且不受理任何資料取回或復原之請求。

5.2 連續十五日未開機或操作

伺服器連續超過 15 日未開機或未有任何操作者，管理員得關閉該伺服器；惟伺服器目前處於開機運作狀態者，本項規定不適用。

5.3 資料備份責任

重要資料（例如 Minecraft 世界檔案、網站原始碼）請使用者自行定期下載備份。因伺服器遭刪除、關閉或故障而致資料遺失者，本服務不負賠償或復原責任。

6. 資料安全與責任

本章規範資料安全、賠償範圍及雙方之責任劃分。

6.1 資料外洩風險自負

本服務為免費主機，不提供企業等級之資料保護保證，使用者應自行評估並承擔相關風險。

6.2 遭受外部攻擊之補償範圍

伺服器遭外部攻擊而發生問題時，本服務僅於可行範圍內協助恢復虛擬內容（例如 Minecraft 建築存檔），不保證能完整恢復。

6.3 不受理金錢賠償

請特別留意

本服務為免費性質，不受理任何形式之金錢、現金或營業損失賠償請求。使用者須同意此項規定，始得使用本服務。

6.4 第三方服務

伺服器運作可能須使用第三方網路、網域、套件、API 或其他外部服務。該等服務之可用性、費用、規則及資料處理方式，由其服務提供者負責。

6.5 使用者內容與法律責任

使用者應確保其上傳、發布或執行之內容未侵害他人權利，並符合適用之法令。因使用者之內容或行為所生之爭議與責任，由使用者自行負責。

6.6 資安事件通報

發現帳號遭盜用、資料外洩或其他安全問題時，請儘速通知管理員並提供必要資訊，以利調查與處理。

6.7 違規損失之賠償

因使用者違反本條款，致 Wayne Free Host 或第三方受有損失、遭受求償或支出法律費用者，使用者應負賠償責任，並配合處理。

7. 管理人員隱私與安全行為準則

管理員及協助管理之工作人員掌握較高之系統權限，因此適用較一般使用者更為嚴格之規範。

7.1 最小權限原則

管理員及工作人員僅取得執行職務所必需之最低權限。職務異動或離開團隊時，其權限、API Key 及 SSH 金鑰應立即撤銷。

7.2 禁止無正當理由查看使用者資料

無正當理由者，不得查看使用者之檔案、主控台、資料庫、日誌或訊息。僅於下列情形得進行存取，且範圍以處理事項所需之最小範圍為限：

  1. 處理檢舉；
  2. 調查違規或資安事件；
  3. 系統維護所必需；
  4. 使用者本人要求協助。

7.3 禁止外洩、轉傳或販售

於管理過程中取得之任何資料（包含 Discord ID、電子郵件、IP 位址、檔案內容、密碼、日誌、截圖及對話），不得複製、轉傳、公開、販售，或用於管理以外之目的。離任後仍負相同義務。

7.4 禁止索取憑證

管理員不得、亦不會向使用者索取密碼、雙重驗證（2FA）驗證碼、API Key 或 Token。需要協助時，應由管理員透過面板之正規流程處理，不得要求使用者提供憑證。

7.5 帳號安全要求

管理員帳號須啟用雙重驗證（2FA），使用高強度且不重複之密碼，不得與他人共用帳號，且不得於公共或不受信任之裝置登入面板。發現帳號或裝置疑似遭入侵時，應立即通報並更換所有憑證。

7.6 敏感操作紀錄

查看使用者檔案、停用或刪除伺服器、解除 IP 封鎖、重設或變更使用者資料等敏感操作，均應記錄原因與時間。不得刪除、竄改或規避面板活動日誌及稽核紀錄。

7.7 禁止濫用權限

不得為自己或他人設置後門、給予超額資源或特權、私下放行違規內容、利用管理員身分規避資源限制，或將節點資源挪作私人用途（包含挖礦）。管理員同樣應遵守第 3 條及第 4 條之規定。

7.8 處置之公平性與證據

處置使用者應依本條款辦理，並保存相關證據（截圖、日誌及時間紀錄），不得挾怨報復、偏袒友人或私下交易。與當事人有利害關係者應迴避，改由其他管理員處理。

7.9 基礎設施機密

Wings Token、面板 API Key、資料庫密碼、.env、SSH 金鑰、Cloudflare Tunnel 憑證及節點內網位置等，屬機密資訊，不得公開、截圖外流或張貼於公開頻道。懷疑外洩時，應立即更換。

7.10 遠端存取與工作環境

管理節點時，僅得使用經授權之方式（面板、SSH 金鑰），不得自行架設未經授權之隧道、遠端控制或代理工具。作業完成後應登出，且不得將使用者資料下載或存放於個人裝置、雲端硬碟或通訊軟體。

7.11 資安事件通報

發現入侵、資料外洩、憑證遺失或其他可疑行為時，應於 24 小時內通報 Wayne，並保留現場證據。隱匿不報者，視為重大違規。

7.12 保密義務與離任

保密義務於任期屆滿後仍然有效。離任時應交還全部憑證、刪除所持有之使用者資料及截圖，並確認帳號權限已移除。

7.13 違反準則之後果

違反本條準則者，立即撤銷其管理權限；情節嚴重者，永久停權並公開處分結果；造成使用者或本服務損失者，應負賠償責任，必要時並依法追究。

8. 隱私權與資料保護

本章說明本服務如何蒐集、使用及保護使用者之個人資料。

8.1 蒐集之資料

本服務蒐集之資料包含：Discord 帳號資訊（ID、名稱、頭像）、登入時之 IP 位址、邀請與點數紀錄、伺服器資源使用量，以及面板與主機產生之活動與系統日誌。本服務不蒐集使用者無須提供之資料。

8.2 蒐集目的

所蒐集之資料僅用於提供服務、防止濫用與多重帳號、處理違規與申訴、維護資訊安全及統計資源使用情形，不用於廣告或其他無關之用途。

8.3 不販售、不公開

本服務不會販售、出租或公開使用者之個人資料。除因法令要求、保護服務安全，或處理使用者與管理員間之爭議外，不會向第三方提供。

8.4 管理員查看檔案之限制

使用者之伺服器檔案、主控台及資料庫，預設為私人。管理員僅得於第 7.2 條所列情形查看，並受第 7 條全部規範拘束。

8.5 保存期限

活動及系統日誌最長保存 90 日；帳號刪除或終止後，個人資料將於 30 日內清除。為防止遭封鎖者重新註冊，黑名單所需之最少識別資料（如 Discord ID、IP 位址）得長期保存。

8.6 使用者之權利

使用者得隨時聯繫管理員，請求查詢、更正或刪除屬於其本人之個人資料；但因進行中之違規調查、資安事件或法令要求而須保留者，不在此限。

8.7 第三方服務之資料處理

登入與通知須經由 Discord，連線亦可能經過 Cloudflare 等網路服務。該等第三方依其自身隱私政策處理資料，本服務無法控制。

8.8 使用者之安全責任

請為 Discord 及相關帳號啟用雙重驗證，勿與他人共用密碼或 API Key，並定期檢查面板之 SFTP 與 API 存取情形。管理員不會向使用者索取密碼或驗證碼；遇有此類要求，請立即回報。

8.9 隱私與安全問題回報

發現隱私外洩、管理員違規查看資料或任何安全漏洞者，請立即於 Discord 通報管理員。善意回報漏洞者，不被追究責任；但禁止利用漏洞取得或破壞他人資料。

9. 違規處置

使用者違反本條款者，管理員得視情節輕重，採取下列處置之一項或數項。

9.1 處置方式

  1. 停用違規伺服器（保留 24 小時供使用者備份，逾期永久刪除）；
  2. 限制或撤銷帳號權限；
  3. 刪除違規伺服器；
  4. 永久註銷帳號並列入黑名單。

9.2 申訴

使用者如認為處置有誤，得於收到通知後 7 日內聯繫管理員提出申訴。

9.3 緊急處置與調查

  • 於維護、資安事件或緊急狀況下，管理員得不經事前通知，立即處理。
  • 調查違規或安全事件期間，管理員得暫時限制伺服器與帳號之功能。
