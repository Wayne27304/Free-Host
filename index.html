Wayne Free Host 服務條款

更新日期：2026 年 10 月 14 日

哈囉！歡迎來到 Wayne Free Host。既然是免費的主機服務，有些醜話還是得先講在前面。只要你註冊跟開了伺服器，就代表你同意底下這些規定。如果看了覺得無法接受，那可能這裏就不太適合你啦～

1. 先講好：這是免費的

這裏所有的資源都是完全免費提供的，所以別要求太多 24 小時專人客服：

  • 1.1 隨時可能調整：因為是免費的，主機要維護、要重組、或者哪天想收掉，管理員（Wayne）都有權利直接改動或關閉服務，不用特別提前通知你。
  • 1.2 沒有保證在線：我們不保證 24/7 永不掛點。社群 Discord 大家的幫忙都是互相的，別把免費主機當成企業級 SLA 級別來要求喔。
  • 1.3 維護與不可抗力：主機偶爾需要停機維護，我們會盡量事先通知，並努力在預定時間內完成。因維護、停電、網路中斷、天災或其他我們無法控制的狀況造成的服務中斷或資料損失，我們不負責任。

2. 帳號跟安全管理

為了公平起見，帳號跟資安有一些基本要求：

  • 2.1 一人一個帳號就好：拜託不要辦一堆小號來洗伺服器資源。抓到開小號多開的，直接全部一起永久封鎖。
  • 2.2 密碼自己顧好：帳號密碼請自己妥善保管，用你帳號幹了什麼壞事，責任就是算在你的頭上。
  • 2.3 連續輸錯三次就封 IP：主機有自動防護，VPS 連續三次密碼打錯來源 IP 就會被系統直接封鎖。如果不小心把自己鎖在外面的話，再來找管理員解封。
  • 2.4 不得轉讓或轉售：未經管理員同意，不得把你的帳號或伺服器轉讓、出租、轉售或分享給其他人使用。

3. 伺服器能開多少？規格是多少？

資源有限，大家互相體諒不要把主機榨乾：

  • 3.1 數量限制：普通用戶最多只能同時開 5 台 伺服器；管理員權限最多 10 台。
  • 3.2 效能配額：普通用戶每台伺服器上限就是 CPU 20%、RAM 512MB。管理員則是不限制。
  • 3.3 別讓 CPU 長時間飆高：不要讓主機 CPU 一小時內長時間維持在 80% 以上，太誇張會直接被系統降級或強制關機。
  • 3.4 磁碟空間上限：普通用戶每台伺服器的磁碟空間（Pterodactyl 面板上的 Disk）上限為 1 GB，管理員另行配置。世界存檔、日誌、暫存檔、模組、node_modules、備份檔等伺服器內所有檔案都計入用量，一律以面板顯示為準。
  • 3.5 超過磁碟配額會怎樣：磁碟用量超過上限時，面板可能阻止伺服器啟動、無法上傳或寫入檔案，並可能導致存檔損毀或遺失。收到通知後請在 48 小時內自行清理；逾期管理員有權直接刪除超額檔案（優先處理日誌、暫存檔與備份）或停用伺服器。因超額造成的資料損毀或遺失，我們不負任何責任。
  • 3.6 不得規避磁碟限制：禁止利用符號連結（symlink）、掛載外部儲存、把資料藏到容器以外的位置、偽造檔案大小或其他方式繞過磁碟配額。被發現者視同違反 4.10，直接停用伺服器。
  • 3.7 備份、資料庫與埠口：每台伺服器最多 1 份備份、1 個資料庫、2 個網路埠口（Allocation）。備份檔請定期下載到自己的電腦，面板上的備份不算是安全的異地備份。
  • 3.8 檔案數量、單檔大小與頻寬：單一伺服器檔案總數不得超過 50,000 個，單一檔案不得超過 500 MB；磁碟 I/O 或網路頻寬長時間異常偏高，影響到其他用戶時，管理員可要求你清理、限速或停用伺服器。

4. 絕對不能做的事（黑名單）

免費歸免費，但有些東西踩下去就是直接掰掰：

  • 4.1 嚴禁挖礦：絕對不准跑任何加密貨幣挖礦程式（像 XMRig 這種）。被系統抓到直接秒封帳號，沒得商量。
  • 4.2 惡意攻擊與爬蟲：禁止拿這裡的主機去發動 DDoS、網路掃描、炸群、或是搞高頻率惡意爬蟲。
  • 4.3 病毒跟木馬：不准放木馬、病毒、勒索軟體或任何怪力亂神的遠端控管後門。
  • 4.4 嚴禁私自搞高風險內網穿透（重點）：為了安全起見，容器內嚴禁私自架設像 sshx、tmate、或是未授權的 ngrok / cloudflared 等高風險隧道工具。抓到直接停用伺服器。
  • 4.5 禁止下載或安裝作業系統：禁止在容器內下載、安裝或執行完整的 Linux、Windows 或其他作業系統映像、ISO、rootfs，或利用容器建立巢狀虛擬機或容器。一般應用程式所需的套件下載不在此限。
  • 4.6 色情與違法內容：禁止任何色情內容（含 AI 生成色情、成人網站等）或違法東西。
  • 4.7 濫用儲存與頻寬：禁止把服務用作公開檔案分享、盜版散布、代理轉發、大量下載站或其他會長時間大量消耗儲存空間與頻寬的用途。
  • 4.8 未經授權的存取：禁止嘗試登入、讀取、修改或破壞其他使用者、伺服器、面板或主機系統的資料與功能。
  • 4.9 垃圾郵件與大量自動化請求：禁止寄送垃圾郵件、批量建立帳號、灌水、騷擾訊息，或以程式持續發送會影響服務穩定性的高頻率請求。
  • 4.10 禁止規避資源限制：禁止透過多開帳號、程序偽裝、漏洞或其他方式規避伺服器數量、CPU、記憶體及頻寬等限制。
  • 4.11 盜版、破解與 BT 下載：禁止存放或散布盜版軟體、破解工具、ROM，也禁止使用 BitTorrent 等 P2P 工具下載或做種；提供這類內容連結或教學的網站同樣不行。
  • 4.12 代理與 IRC：禁止架設代理（Proxy）或 VPN 轉發節點，也禁止建立或連接 IRC 網路伺服器。第一次違規會停用伺服器，再犯直接終止帳號。
  • 4.13 不實與誹謗內容：禁止架設散布不實資訊，或誹謗、抹黑個人、團體、企業的網站與服務。
  • 4.14 冒充與社交工程：禁止冒充管理員、工作人員或其他用戶，也禁止以任何話術騙取他人的密碼、驗證碼、Token 或權限。
  • 4.15 侵犯他人隱私：禁止蒐集、公開、交易他人的個人資料（含人肉搜索、截圖外流 Discord 私訊與管理員對話），也禁止在伺服器上架設未經同意蒐集他人資料的網站或程式。
  • 4.16 濫用面板與 API：禁止暴力嘗試登入、濫用面板 API 或 SFTP、短時間反覆建立與刪除伺服器，或以任何方式探測面板與節點的漏洞。
  • 4.17 外洩憑證與敏感資料：禁止把面板帳密、API Key、SFTP 密碼、Token 或 .env 內容公開或貼到公開場合；因此被盜用造成的後果由你自己負責。

5. 伺服器閒置與回收規則

請定期使用並維持伺服器狀態：

  • 5.1 建立後 7 天內無動作將刪除：伺服器建立後，如果在 7 天內沒有開機、登入、部署或其他操作，管理員有權直接刪除該伺服器，且不接受任何資料取回或恢復要求。
  • 5.2 超過 15 天未開機或操作將關閉：伺服器若連續超過 15 天沒有開機或任何操作，管理員有權關閉該伺服器；如果伺服器目前已經開機運作，此條規則不生效。
  • 5.3 資料要自己備份：重要存檔（例如 Minecraft 世界檔案、網頁原始碼）請自己定時下載備份到電腦。伺服器被刪除、關閉或故障導致資料不見，我們不負賠償或恢復責任。

7. 管理人員隱私與安全行為準則

管理員手上握有很大的權限，所以對管理員與協助管理的工作人員，要求比一般用戶更嚴格：

  • 7.1 最小權限原則：管理員與工作人員只取得完成工作所需的最低權限，不需要的權限一律不給；職務異動或離開團隊時，權限、API Key 與 SSH 金鑰必須立即撤銷。
  • 7.2 不得無故查看用戶資料：禁止在沒有正當理由的情況下查看用戶的檔案、主控台、資料庫、日誌或訊息。僅限以下情況可存取：處理檢舉、調查違規或安全事件、系統維護必要、用戶本人要求協助；存取範圍僅限於處理事情所需的最小範圍。
  • 7.3 禁止外洩、轉傳或販售：任何在管理過程中接觸到的資料（Discord ID、Email、IP、檔案內容、密碼、日誌、截圖、對話）都不得複製、轉傳、公開、販售或用於管理以外的目的，離任後此義務依然有效。
  • 7.4 不得索取密碼或驗證碼：管理員永遠不會、也不得向用戶索取密碼、2FA 驗證碼、API Key 或 Token。需要協助時，應由管理員在面板上透過正規流程處理，不得要求用戶提供憑證。
  • 7.5 帳號強制安全要求：管理員帳號必須啟用雙重驗證（2FA）、使用高強度且不重複的密碼、不得與他人共用帳號，也不得在公共或不受信任的裝置上登入面板；發現帳號或裝置疑似遭入侵，須立即通報並更換所有憑證。
  • 7.6 敏感操作須留紀錄：查看用戶檔案、停用或刪除伺服器、解封 IP、重設或變更用戶資料等敏感操作，都必須留下原因與時間紀錄；禁止刪除、竄改或規避面板活動日誌與稽核紀錄。

  • 7.8 處置須公平且有憑證：處置用戶必須依本條款執行並保留證據（截圖、日誌、時間），不得挾怨報復、偏袒朋友或私下交易；與當事人有利害關係時必須迴避，交由其他管理員處理。
  • 7.9 基礎設施機密：Wings Token、面板 API Key、資料庫密碼、.env、SSH 金鑰、Cloudflare Tunnel 憑證、節點內網位置等屬於機密，不得公開、截圖外流或貼到公開頻道；懷疑外洩時必須立即更換。
  • 7.10 遠端存取與工作環境：管理節點時只能使用經授權的方式（面板、SSH 金鑰），禁止自行架設未授權的隧道、遠端控制或代理工具；處理完畢後須登出，並不得把用戶資料下載或存放在個人裝置、雲端硬碟或聊天軟體。

8. 隱私權與資料安全

你的資料我們怎麼處理，白紙黑字寫清楚：

  • 8.1 我們會蒐集哪些資料：Discord 帳號資訊（ID、名稱、頭像）、登入時的 IP 位址、邀請與點數紀錄、伺服器資源使用量，以及面板與主機產生的活動與系統日誌。我們不會蒐集你不需要提供的資料。
  • 8.2 蒐集目的：資料僅用於提供服務、防止濫用與多開、處理違規與申訴、維護資安與統計資源使用，不會用於廣告或其他無關用途。
  • 8.3 不販售、不公開：我們不會販售、出租或公開你的個人資料；除了因為法律要求、保護服務安全，或處理你與管理員之間的爭議，否則不會提供給第三方。
  • 8.4 管理員查看檔案的限制：你的伺服器檔案、主控台與資料庫預設是私人的，管理員只會在第 7.2 條列出的情況下查看，且受第 7 條所有規範約束。
  • 8.5 保存期限：活動與系統日誌最多保留 90 天；帳號被刪除或終止後，個人資料會在 30 天內清除。為了防止被封鎖者重新註冊，黑名單所需的最少識別資料（如 Discord ID、IP）可長期保留。
  • 8.6 你的權利：你可以隨時聯絡管理員，要求查詢、更正或刪除屬於你的個人資料；但為了處理中的違規調查、資安事件或法律要求而必須保留的資料除外。
  • 8.7 第三方服務的資料：登入與通知會經過 Discord，連線可能經過 Cloudflare 等網路服務，這些第三方依其自身隱私政策處理資料，我們無法控制。
  • 8.8 用戶自身的安全責任：請為你的 Discord 與相關帳號啟用雙重驗證，不要與他人共用密碼或 API Key，並定期檢查面板的 SFTP 與 API 存取。管理員永遠不會向你索取密碼或驗證碼，遇到有人這樣要求請立即回報。
  • 8.9 隱私與安全問題回報：發現隱私外洩、管理員違規查看資料或任何安全漏洞，請立即在 Discord 通報管理員；善意回報漏洞者不會被追究，但禁止利用漏洞取得或破壞他人資料。

9. 違規會怎樣？

如果你踩到底線，管理員就會動手：

  • 直接停用伺服器（會保留 24 小時讓你想辦法備份，逾期永久刪除）
  • 限制或拔掉你的帳號權限
  • 把違規的伺服器直接刪掉
  • 永久註銷帳號並把你丟進黑名單
  • 如果你認為處置有誤，可在收到通知後 7 天內聯絡管理員提出申訴
  • 維護、資安事件或緊急狀況下，管理員可不經事前通知立即處理
  • 調查違規或安全事件期間，管理員可暫時限制伺服器與帳號功能
  • 處理爭議時，可參考面板、主機與網路服務所產生的系統紀錄
  • 帳號遭終止後，不得以其他帳號或方式規避處分並重新使用服務
  • 對管理員或工作人員惡意辱罵、騷擾或態度惡劣者，管理員可直接終止帳號
  • 對管理員或本服務威脅提告者，帳號將直接終止；有爭議請先好好溝通
  • 管理員違反第 7 條準則時，立即撤權並依第 7.13 條處理
  • 嚴重違規（含外洩他人隱私、入侵、攻擊）可不經警告直接終止帳號；同一人多次違規，處分可累計加重

被處置時基本上都會透過 Discord 跟你說一聲。
